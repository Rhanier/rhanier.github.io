Crie uma webpage interativa infantil, em um único arquivo HTML com CSS e JavaScript embutidos, pensada para ajudar uma criança a visualizar a passagem do tempo de forma divertida e fácil de entender.

A página deve permitir que o responsável digite ou selecione um tempo em minutos e inicie uma contagem regressiva visual. Conforme o tempo passa, a criança deve ver claramente o progresso desse tempo por meio de elementos grandes, coloridos e animados, como barra de progresso, círculo de progresso, personagens, estrelas, foguete, arco-íris ou outra metáfora lúdica amigável para crianças.

Requisitos funcionais:

Campo para definir o tempo em minutos.
Botões grandes para iniciar, pausar, retomar e reiniciar.
Exibição do tempo restante em números grandes.
Barra de progresso animada mostrando quanto tempo já passou.
Um elemento visual infantil que evolui com o tempo, por exemplo: um foguete andando até o destino, uma trilha sendo completada, estrelas sendo acesas ou uma imagem sendo revelada aos poucos.
Marcos visuais claros em 25%, 50%, 75% e 100% do tempo.
Mensagem final amigável quando o tempo acabar, como “Parabéns! O tempo terminou!”.
Som opcional no fim, com botão para ativar ou desativar áudio.
Interface totalmente responsiva para celular e desktop.
Acessibilidade básica, com contraste bom, botões grandes e textos fáceis de ler.

Requisitos de design:

Estilo alegre, infantil, limpo e moderno, sem excesso de informação.
Visual colorido, mas organizado, com cores suaves e amigáveis.
Ícones e ilustrações simples em SVG ou CSS, sem depender de imagens externas.
Tipografia grande e legível.
Animações suaves e divertidas, mas não exageradas.
Deve parecer um “timer mágico” para crianças de aproximadamente 4 a 9 anos.

Entregue tudo em um único arquivo HTML.

Não use frameworks.

Use apenas HTML, CSS e JavaScript puro.

O código deve estar organizado e pronto para rodar localmente.

Não use localStorage.

Inclua comentários curtos explicando as partes principais.

Garanta bom funcionamento mesmo sem internet.

Quero que a página tenha um toque emocional e lúdico, para a criança sentir que está avançando em uma pequena missão enquanto o tempo passa. O objetivo é ajudar em atividades como escovar os dentes, estudar, guardar brinquedos ou esperar a hora de sair.

No final, entregue:

O código completo.

Uma breve explicação de como personalizar tema, cores e personagem.

Sugestões de variações, como tema de foguete, dinossauro, princesa, floresta ou corrida.
